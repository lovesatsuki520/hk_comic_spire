# 《港漫尖塔：群俠武神傳》模組化專案架構說明

本專案將你原有的 `data.js`（10 大羈絆、17 位常駐角色、合體神卡【安迪與奧本海默】、第 8 關終極 Boss【楊守正】與 14 款海克斯增幅）全面改造為**港漫粵語古風《殺戮尖塔》單人闖關卡牌遊戲**。

## 📁 檔案分類與日後維護指南

為了方便你日後在 GitHub 上直接修改數值、新增朋友角色或調整平衡，所有程式碼已按功能拆分為獨立模組，**永遠不需要由頭到尾重寫**：

```text
hk_comic_spire/
├── index.html              # 遊戲主入口（上傳 GitHub Pages 後直接點開即可遊玩）
├── css/
│   └── hk_comic.css        # 【視覺風格模組】港漫分鏡黑框、網點、大字氣功特效與卡牌外觀
├── data/
│   ├── heroes.js           # 【主角資料模組】4大可選開局主角（DC齊發達、FreeTed、DV、鼠姐）與起始牌組
│   ├── cards.js            # 【武學卡牌模組】10大舊羈絆轉化之心法卡 + 17位角色絕學卡 + ★3極意升級數值
│   ├── relics_events.js    # 【法寶與奇遇模組】14款海克斯神兵（大力生菜、破產保護令等）與「?」奇遇事件
│   └── enemies.js          # 【八重魔宮關卡模組】1~7層守關堂主與第8層終極Boss「楊守正（100%中的100%）」
└── js/
    ├── audio.js            # 【音效合成模組】Web Audio API 港漫拳風、金鐘護體、十成功力音效
    ├── engine.js           # 【核心戰鬥引擎】抽牌、洗牌、真氣結算、薛丁格姿態、無慘鬼化、楊守正半血狂暴
    └── ui.js               # 【畫面渲染模組】港漫黃底旁白框、手牌互動、閉關升級視窗與武林全圖鑑
```

## 🛠️ 常見修改範例

1. **想新增一張朋友的武學卡？**
   打開 `data/cards.js`，在 `CARD_DB` 複製任一張卡的格式，填入 `name`、`shout`（港漫台詞）、`effects`（傷害 `dmg`、護盾 `block`、回血 `heal`、抽牌 `draw`），儲存即可自動加入獎勵卡池與圖鑑！
2. **想調整 Boss 楊守正的血量或招式？**
   打開 `data/enemies.js`，找到第 8 層 `boss_yeung`，修改 `maxHp` 或 `intents` 陣列即可。
3. **想新增第 5 位可選開局主角？**
   打開 `data/heroes.js`，在 `PLAYABLE_HEROES` 陣列加一個物件，選角畫面就會自動多出該主角！
